# Education Website - High School Supplemental Learning Platform

A scalable EdTech marketplace connecting instructors with high school students. Instructors create courses with AI assistance, students subscribe to individual courses.

## Tech Stack

- **Frontend:** Next.js 14+ with TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Next.js API Routes, PostgreSQL, Prisma
- **Auth:** NextAuth.js
- **Payments:** Stripe
- **Hosting:** Vercel
